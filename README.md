# Daniel Game Minecraft

这是一个完全基于 HTML5、Three.js 和 Web Audio API 构建的 3D《我的世界》网页版克隆项目。
包含代码合成音效、程序化地形生成，以及通过房间码连接的 WebRTC 多人联机。

## 功能特点
- **完全方块化材质**：没有绝对的圆形，所有贴图（草地、原木、泥土）均为 16x16 像素噪点随机生成。
- **极致的无限挖掘**：采用动态表面剔除算法，向下挖 10000 层也不会卡顿。
- **纯粹的合成音效**：没有使用任何现成的 MP3 录音。泥土的“沙沙”声、石头的“咣咣”声、玻璃破碎的“叮当”声全部通过 Web Audio API 纯代码实时物理合成。
- **多人联机**：房主创建房间后获得可复制的 12 位联机码。朋友加入时加载房主的世界，双方可以看到彼此并同步普通方块的放置和挖掘。
- **丰富的机制**：包含核弹爆炸、枪械射线检测、火把供电的熔炉、村民建造彩蛋、以及水下窒息（20秒）等物理机制。

## 如何运行单人游戏
可以直接打开 `game3d.html`，但要保留同目录的脚本文件。单人游戏的 Three.js r128 和控制脚本随项目提供，不需从外站下载；联机服务仍需要联网。第三方库许可证见 `three-r128-LICENSE.txt`。也可以启动本地服务器：

1. 确保你安装了 Python 3 或 Node.js
2. 在项目根目录下打开终端
3. 运行本地服务器：
   - Python: `python3 -m http.server 8000`
   - Node.js: `npx serve -p 8000`
4. 打开浏览器访问：[http://localhost:8000/game3d.html](http://localhost:8000/game3d.html)

## 挖掘和跑步
- 创造模式：左键点一下立即打碎普通方块，不必按住等待裂痕；仍散出少量同色小碎屑，落地后淡出，并保留原有的小方块掉落物。
- 生存模式：仍按材料和工具决定挖掘时间，松开左键会取消未完成的挖掘。缩小后仍只挖一个微方块，不会挖掉整个大方块。
- 按住左边或右边的 **Shift**，同时按 W/A/S/D，步行速度变为约 **1.6 倍**；松开 Shift 恢复正常。缩小后按身体比例加速，碰撞不变。游泳、爬梯、创造飞行、车辆和机甲保持原来的速度。
- 暂停、切到其他窗口或打开背包会清除按键状态，避免回来后一直跑。

`node tests/mining-sprint.cjs` 检查真实鼠标/键盘操作、碎屑落地与回收、创造/生存差异、缩小比例及桌面/手机画面。

## 如何联机
1. 双方打开同一个最新版网页，点击 **Play with Others**。
2. 房主点击 **Create Room**，等待显示 **Room ready.**，点击 **Copy** 把联机码发给朋友，再点击 **Enter Room**。
3. 朋友选择 **Join Room**，粘贴联机码，点击 **Join Room**。世界加载完成后点击 **Enter Room**。
4. 按 Esc 后点击 **Room** 可以复制联机码或点击 **Leave Room** 退出。

房主必须保持网页打开。新建房间会产生新码，旧版 IP 地址式联机码不能使用。请只把联机码发给信任的朋友。房主断开后，客人仍可在当前世界单人游玩并下载存档。

当前实现使用随项目提供的 PeerJS 1.5.5，通过公共 PeerJS 信令服务建立 WebRTC 数据连接，并使用该库默认的 STUN/TURN 配置。无需运行旧的 `server.py`，也无需开放 8081 端口。双方网络仍须能访问这些服务；连接失败或超时会显示提示，可以重试。

目前同步世界初始存档、玩家位置、普通方块编辑和家具放置。生物 AI、车辆、缩小后的微方块编辑及家具操作尚未完整实时同步；重建世界、另载存档或切换维度会退出房间。大于 16,777,216 字符的世界存档暂不传输。联机不是公共服务器管理系统，不提供账号权限或反作弊。

## GitHub Pages 部署
发布完整项目文件，不能只上传 `game3d.html`。在仓库 **Settings > Pages** 中选择 **Deploy from a branch**、**main**、**/(root)**，保存并等待部署完成。

现有游戏入口：[Daniel Game Minecraft](https://vickysy.github.io/MineWorld-3D4/game3d.html)。GitHub Pages 提供静态网页；联机信令和中继由上述外部服务提供，不是在 GitHub 上运行后端服务器。

## 岩浆、火焰和核爆
- **岩浆桶（Lava Bucket）**：在 Tools 分类选择。空桶右键舀岩浆，岩浆桶右键一次铺开最多 128 格；生存模式只消耗一桶并返还空桶。只填相连的可用空间，墙壁和植物不被替换，空间不足就少填。岩浆随后向下流动并向四周摊开。
- **岩浆反应**：不会融化、烧掉或点燃周围任何方块，也不会引爆 TNT。与水接触时仍生成黑曜石，并消耗少量水产生蒸汽。生存模式中接触岩浆仍会受伤。
- **打火器（Flint and Steel）**：Tools 分类，右键点燃树木、TNT 或 Nuke。生存模式用 1 铁矿 + 2 石头合成，获得后可重复使用。普通火会蔓延并烧完相连木头和树叶，遇水熄灭。
- **篝火（Campfire）**：Home 分类，放置后持续燃烧，不会自动熄灭。配方为 3 木头 + 2 石头 + 1 火把。
- **Nuke**：新爆炸缩小为直径约20格、最深约9格的半球形坑，保留实体坑底。TNT威力不变。旧坑不会自动恢复，旧存档中已经开始的大坑任务仍按原尺寸完成。先保存世界，再测试核弹。

两人都须刷新到新版后重新创建房间。新增的火焰、岩浆水位和核爆坑同步到房间内其他玩家；原有生物和车辆的同步限制不变。

`node tests/thermal-world.cjs` 检查流动、遇水反应、燃烧、合成、实际右键操作、存档及桌面/手机 3D 画面。

## 活塞、弹跳板和 TNT 机关
- **Piston（活塞）**：推动物体的机械装置，外形是一个方块底座、连接杆和推板，伸出时整体约一个半方块长。新放的活塞推板朝向放置它的玩家；正上方或正下方放置时可竖向朝向玩家。拿 Pickaxe（镐）右键点活塞或推板，选择 Auto / Door / TNT Cannon / Cycle。面板里的 Rotate 可旋转未伸出的活塞，原有存档保留方向和循环行为。
- **Auto（自动判断）**：新活塞默认使用此模式。在推板前放普通可推动方块，会设成 Door；放 TNT，会设成 TNT Cannon；空着时保持原来的通电循环行为。判断为门或炮台后会记住模式，不会因门板移走而改变。要改用途，用镐右键重新选择。
- **Door（门）**：初始断电时活塞伸出、门板合上。第一次开拉杆会缩回，拉杆开着就一直保持打开。断电后至少再等8秒才关门；人在门洞内或门边时继续等待，离开后才关。按钮虽然只输出一秒信号，门也不会一秒就合上。TNT Cannon 和 Cycle 不作为通行门使用。
- **TNT Cannon（炮台）**：初始缩回。每次拉杆从关变开才推出一次；回缩后即使拉杆仍开着，也不会不停往复。**Cycle（循环）** 保留持续“推出、缩回、再推出”的玩法。
- **五格供电、八个活塞**：打开的拉杆只需位于红石五格以内，不必相邻；距离按三维直线计算，正好五格也有效。一份通电红石最多带动五格以内最近的八个活塞，可上下叠放，不用给每个活塞单独放红石。第九个需要再补一份通电红石。相连的红石仍可继续延伸线路，普通墙壁不会屏蔽这个五格范围。
- **Pressure Plate（压力板）**：地上的薄板。旁边接红石，再连接打开的拉杆，就成为 **Jump Pad（弹跳板）**；踩上去会把玩家向上、向前弹出去。弹跳板弹的是人，活塞推的是方块，两者不是同一个东西。
- **Redstone Dust（红石粉）**：在背包 Redstone 分类中选择，右键铺在实心方块上。相邻红石粉自动连接并显示分叉，支持一格台阶，通电变亮。拉杆距离任意接入点五格以内即可启动整条连接线路；按钮紧挨线路发送一秒脉冲。线路末端必须贴着活塞，可分叉连接八个甚至更多活塞。中途挖断且断点后没有其他电源时，下游停止供电。普通 Redstone（红石块）仍保留五格内带动最多八个活塞的规则。生存合成：1 红石 = 8 红石粉；1 石头 = 1 Button（按钮）。按钮可装在地面或墙面，右键按下后自动弹回。
- **闸门**：上下各放一个同向活塞，各自前面放一块石头、玻璃或其他普通方块，将它们设为 Door，并接到同一条红石线上。伸出时门板在活塞前方第二格，缩回时退到第一格，给第二格的门洞留出通路。每个活塞最多推动一排12格；遇到人、不可推动的物体或没有空间会停住，不会直接删掉障碍。家具、完整门/床、黑曜石、屏障以及已被微挖掘的方块不可推动。
- **隐藏红石**：拿 Redstone（红石）右键点 Hidden Stone/Hidden Dirt/Hidden Grass，即可把一份红石装在隐藏方块内部；也可以拿隐藏方块覆盖现有红石。六个相邻方向都能接线，隐藏后的红石仍遵守五格供电、最多八个活塞的规则。挖掉隐藏方块时，红石也会掉出来。
- **悬空 TNT**：失去下面的支撑就会落下；没点燃时落地仍是 TNT，不会凭空爆炸。打火器、火把或通电红石会点燃约4秒引信，闪白后爆炸。
- **游戏内 TNT 发射器**：让活塞朝向空地，在推板前放 TNT，可以在同一位置向上叠最多16个；活塞下方放红石，红石旁边放拉杆。拉杆打开后先点燃并闪白，约0.45秒后向前抛出，碰到地面或墙壁才爆炸；没有碰到东西时8秒后自动引爆。场地应留出至少30格空地，先保存世界再试。这个机关是本游戏的自定义玩法，不是原版红石规则。
- **村民与岩浆**：村民身体碰到岩浆会逐次变红、扣血，持续接触会倒下并化成灰；站在旁边或隔着墙不会受伤。

活塞模式和方向、隐藏红石、按钮剩余时间、推拉状态和飞行中的 TNT 都随存档保存。联机由房主计算 TNT、按钮和活塞，双方需刷新到同一新版后重新建房；村民 AI 仍不是完整联机同步。`node tests/redstone-machines.cjs` 验证机关、引信、碰撞、存档和画面。

## 密码锁
- 在背包 **Redstone** 中选择 **Password Lock**，装在墙面或地面上，锁所在格紧挨红石粉/红石即可接入整条线路；也可贴在装有隐藏红石的方块外侧。门活塞选 **Door**。配方：2 铁矿 + 1 红石。
- 放置后输入自定密码，按 **Set Code**。之后右键点锁，输入密码并按 **Unlock**；正确才通电开门。英文、数字、中文均可，长度1至64字符，空格和大小写也算密码的一部分。请只用游戏密码，不要使用真实账号密码。
- 同线路的普通拉杆、按钮不能绕过密码。访客可以凭正确密码开门，但不能修改已接入的红石线路、活塞设置或门板，也不能修改密码或拆锁。连续输错5次，需等待30秒。
- 只有放置者能用 **Change Code** 改密码，或用 **Remove Lock** / 左键拆锁。拆除返还一个锁；炸弹、流体、拆支撑方块不会让锁自动掉落。设置、拆除及密码验证由房主校验，密码原文不保存，密码校验值不发送给访客。
- 放置者身份保存在当前浏览器的网站数据中，重新进入仍有效；换浏览器、换网址来源或清除网站数据不会自动继承身份，请先拆锁再迁移。世界存档保存锁的位置、归属和密码校验值，不保存浏览器的身份密钥。请保留原浏览器和房主存档。
- 这是游戏内门锁，不是整栋房子的防拆保护，也不是防外挂服务器。其他普通墙壁仍可挖掘；房主控制的网页和存档本身属于信任边界。缩小体素和生物仍有原来的联机限制。

`node tests/password-locks.cjs` 检查门口安全延时、密码和所有权、存档、实际按钮与桌面/手机画面；`node tests/multiplayer.cjs` 检查真实双人联机权限。

## 转动监控与双口发射器
- 摄像头和电脑/平板的监控画面中均有 **Pan** 滑块，左右各 90 度，总范围 180 度。勾选 **Auto Scan** 自动往返，监控镜头和实况画面一起转动。
- 在 Home 中放置 **Twin Nuclear Launcher**，拿 **Surveillance Tablet** 右键打开，切换 **Launchers**。
- 在地图上点击落点，或填写 Target X/Y/Z，然后按 **Launch 1** 或 **Launch 2**。两个发射口分别装填，每口冷却10秒，最大目标距离512格，爆炸直径约20格。
- 地图标出命令生成的楼房/城堡、可识别的普通建材建筑和家的位置，列表显示坐标。可切换 Nearby / Full range。圈选区域涉及这些建筑或自己时显示 DANGER，必须额外点击 **Confirm Launch** 才会发射；改坐标或点击 Cancel 会取消确认。普通方块仍显示为地图上的浅色点；这不是能识别所有任意造型建筑的AI，也不会令建筑免疫爆炸。
- 发射器配方：3 铁矿 + 2 石头 + 1 红石 + 1 Nuke。发射前请下载存档。

## 大型场地命令
点击“命令”，输入后先检查预览，再执行：

```text
field 100×100×100
场地 200×200×10
100×100
城墙 厚5 长100 宽100
城墙 厚5 长100 宽100 高20
```

三组数字按长、宽、高解析，场地有地板和四周墙壁，但不封顶，内部留空。两组数字按墙的长、高解析，默认厚度1格。城墙未写高度时默认10格。支持中文数字、乘/乘以、x、* 和长宽高句式。

长、宽、高上限各200格，墙厚上限20格，同时保留最多32个大型建造区域。使用紧凑区域数据和分批修改，不会为100×100×100的空心空间创建100万个独立物体。未知、否定或含糊的命令会要求补充，不是可以执行任意要求的通用AI。

大型建造暂需单人执行，完成后重新创建房间，朋友加入即可加载新场地。大型建造的“撤销”恢复建造前的完整世界快照，之后的其他修改也会撤回，执行前会明确提示。普通小房间命令仍沿用局部撤销。

`node tests/world-tools.cjs` 验证监控转动和实况像素、平板双口发射、场地尺寸、无顶结构、存档恢复、撤销及手机排版。

## 楼房和四角城楼命令
点击“命令”，输入后先检查尺寸预览，再执行：

```text
房子 20×21 每层高3 10层
帮我设计一个20乘21的楼房，一层为3格，共十层
城楼四角 间隔20 高12
城楼四角 每座6×6 间隔30 高20
城楼加城墙 长50 宽50 厚5 高10；四角城楼 高12 宽4 长4
```

楼房的长宽是外部占地；每层高度按室内净高计算，楼板另占1格。20×21、净高3格的10层楼有10个可布置的楼层，总高41格（含屋顶护栏）。自动设置门窗、两格宽的方块楼梯、贯通所有楼层的爬梯和照明。可跳上楼梯，也可在爬梯处按空格上楼。没写层数时默认1层，没写层高时默认净高3格。楼房最小长宽8格；高层高的楼房需要更长的楼梯，长度至少为净高+4格。净高支持3到12格，总高不超过200格。

“城楼”默认生成四座4×4格的空心角楼，排在正方形四角，入口朝向中间露天庭院，内部爬梯通到垛口屋顶。间隔是相邻两座楼外墙之间的净空距离，不是中心距离；例如4格城楼加20格间隔，总占地28×28格。默认间隔20格、高12格；可指定4到16格的正方形塔楼，高度5到200格，总占地边长不超过200格。庭院有地板，不自动生成连接城墙。

“城楼加城墙”则一次生成连接好的围墙和四座角楼：上例总占地50×50，墙厚5格、高10格，四座城楼各4×4、高12格。墙和城楼的尺寸分开填写，城楼至少比墙高2格。自动留出城门、通往四座楼的通道和登上城墙的爬梯；即使墙比城楼厚，也不会封死入口。只写城墙尺寸时，城楼默认4×4、高出墙2格。

与大型场地一样，需要先单人建好再创建联机房间。执行会替换范围内原有建筑，撤销会恢复建造前的整个世界，请先保存。生成的墙、楼板都可以挖掘或改建，并随世界存档保存。

`node tests/buildings.cjs` 检查中文句式、十层楼结构、楼梯净空、实际爬梯、四角间距、存档恢复、撤销及桌面/手机画面。

## 联机回归测试
`node tests/multiplayer.cjs` 使用两个独立的 Playwright 浏览器会话测试真实信令、房间进入、世界同步、方块编辑、退出重连和失败恢复。可通过 `GAME_URL` 指向已部署版本，通过 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH` 指定本机依赖。

## 缩小家具与瞄准炮台
缩小后，家具按实际桌腿、桌面、柜壁和隔板碰撞，可以进入桌底和家具空隙。冰箱、储物柜增加真实空腔，右键打开面板后选择 `Open Door` / `Open Doors`，关掉面板后门仍保持开启。实心部件不能穿透；正常大小时的家具碰撞保持原样。

天然和整格放置的土块、草地块有一层厚度为 `1/20` 格的外壳，内部为空。先挖开足够人物通过的入口，再缩小进入；内壁、地板和顶板都实际存在，不会看穿地下。每次仍只挖当前缩小比例的一小格，石头等其他地形仍保留实心内部；空腔里的微型放置及外壳挖掘随存档保存。

点击“命令”，输入并检查后执行：

```text
建造炮台
建造双重炮
建造活塞门
```

装置在人物前方的空地生成，不覆盖已有房屋。双重炮装入上下两枚 TNT，依次发射时从上往下，每枚间隔0.9秒；也可以只发一枚。普通手持物品时，在1秒内双击右键炮台或其 TNT，打开 `TNT Cannon` 瞄准图。点地图或填写 X/Y/Z，`Fire One` 发最上面一枚，`Fire Sequence` 依次发射整列。镐的右键仍用于调整活塞模式。目标水平距离6至96格、高度差最多32格；炮弹走实际抛物线，遇到挡路的墙或地面会提前爆炸，不会穿过障碍直达目标。

活塞门有两个方向共四个活塞、红石和拉杆，默认关闭，拉杆开启后保持通行，关闭沿用延时防夹。命令装置需单人建造后创建房间分享，联机中的瞄准发射由房主计算并同步。未使用、未改动的装置可用“撤销”恢复原地；已经使用的装置不会强行回滚，避免破坏后续修改。

`node tests/tiny-home-cannons.cjs` 检查家具实际碰撞、空心土块六面内壁、存档、单发与逐发顺序、命令装置、真实双击瞄准交互及桌面/手机渲染。
